# Образцы

- `договор-подряда-образец.docx` — тестовый договор для формы «договоры» на «Ролях»
  (2026-09-15). В нём 19 плейсхолдеров вида `[(ключ): описание]`, включая
  обязательные `[(sum): …]`, `[(start): …]`, `[(end): …]`; место подписи стороны 1
  (заказчик) выделено сплошной рамкой, стороны 2 (исполнитель) — пунктирной.
  Собран `buildDocx` из `server/src/lib/docx.js`; проверен `placeholdersOf`,
  `signatureFrames` и `docxToHtml`.
